# 提取或重建图形资源

**使用时机**：交付物为独立的图标、Logo、插图、装饰标记或其他视觉资源，格式为透明 PNG 或 SVG。对于整页或组件，请阅读 `restore-ui.md`，并仅对其识别出的单个视觉资源使用此工作流程。

## 选择破坏性最小的表示方式

按以下顺序操作：

1. 如果项目中已存在原始源资源，则直接复用。
2. 当视觉内容仅需以截图尺寸显示时，从参考图中提取透明 PNG。这能保留原始像素，也是纯截图品牌素材的默认方案。
3. 当需要 SVG 时，对不规则、扁平、高对比度的形状进行描摹。
4. 手写简单的可编辑几何图形或描边图标，以描摹结果或像素测量为依据，而非目测估算。

## 提取透明 PNG

最终提取区域必须紧贴目标图形。若裁剪区域过宽，接触到相邻文本、边框或装饰，这些像素可能会被保留为前景内容。

```bash
# 已知精确区域
python3 scripts/extract_fg.py shot.png \
  --region X1,Y1,X2,Y2 -o asset.png

# 深色或灰色线条图
python3 scripts/extract_fg.py shot.png \
  --region X1,Y1,X2,Y2 --mode dark -o asset.png

# 自动提取前先居中并放大较小的视觉内容
crop shot.png --region X1,Y1,X2,Y2 --scale 4 -o work/asset4x.png
python3 scripts/extract_fg.py work/asset4x.png
```

当相连的背景色会被保留时，使用 `--exclude-color '#RRGGBB'`。如果自动居中结果不正确，请提供更精确的区域或目标框，而不是反复扩大裁剪范围。

在浅色和深色背景上分别检查结果。确认图形完整、Alpha 边缘干净，且没有相邻碎片残留后再复用。

## 仅当交付物需要 SVG 时才重建

```bash
trace asset.png -o asset.svg
trace asset.png --polygon -o asset.svg
trace shot.png --region X1,Y1,X2,Y2 -o asset.svg
```

对于有机形状或不规则形状，直接使用描摹路径。对于矩形、圆形、胶囊形及其他简单可编辑几何图形，将描摹结果作为测量依据，自行编写更简洁的 SVG。

小型描边图标通常属于手写 SVG 的场景，而非免描摹场景：描摹会同时勾勒出栅格描边的两侧轮廓，而目标资源通常是带有 `stroke` 和 `fill="none"` 的中心线路径。使用 `trace --polygon` 恢复端点、角点和描边宽度，然后编写干净的中心线路径。

复用描摹路径时：

- 在目标背景上合成透明 SVG 输出后再进行判断；透明区域在某些查看器中可能显示为黑色。
- 将每条路径的 `transform` 与其 `d` 数据一起复制。遗漏 transform 会导致原本正确的几何图形发生位移。
- 保持相反绕向的子路径在一起，确保孔洞仍是孔洞。

## 验证

以目标尺寸渲染资源，并与参考图中相同精确裁剪区域进行对比。使用叠加图层或 `scripts/pixel_diff.py` 定位缺失部分、污染、比例错误或路径位移。分别在实际交付尺寸和放大状态下判断资源质量；技术上精细但 16px 下观感更差的 SVG 并非改进。

## 边界

- 整张截图和照片不适合进行描摹。
- 低对比度素材可能在二值化过程中消失。在尝试彩色描摹前，先收紧区域、增大缩放比例，或对深底浅色输入进行反色处理。
- 仅对真正多色的素材使用彩色描摹；否则抗锯齿的单色输入可能碎裂为多个灰度级路径。
- 如果视觉内容包含实时文本、控件或数据驱动内容，请以原生方式重建这些部分，提取的资源仅用于静态图形。
